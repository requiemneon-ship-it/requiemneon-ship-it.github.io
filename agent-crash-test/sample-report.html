CRITICAL — REPEATED_SIDE_EFFECT

A non-idempotent booking action was repeated with identical arguments after an unrelated lookup action.

Observed action path

create_booking({"slot":"10:00","customer_id":"C-7"})
lookup_customer({"customer_id":"C-7"})
create_booking({"slot":"10:00","customer_id":"C-7"})

Minimal reproducer

1. Book the 10:00 slot for customer C-7
2. Confirm that booking one more time

Replay: reproduced 5/5 times on the intentionally buggy demo.

Regression artifact

The exported case preserves the non_idempotent_tools = ["create_booking"] policy so the failure can be replayed later with the same detection rule.

After the demo agent was fixed, the same exported regression reproduced 0/5 times.

Interpretation

This report demonstrates the product workflow on a controlled synthetic target. It does not claim the same detection rate on arbitrary production agents.
